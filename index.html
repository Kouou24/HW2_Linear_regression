GitHub Pages 部署指引 (Deploy to github.io)

本專案前端採用純靜態無伺服器架構，可直接免費託管於 GitHub Pages：

步驟 1: 推送程式碼

將所有檔案提交並推送至 GitHub 儲存庫 main 分支：
git add . ; git commit -m "update" ; git push origin main

步驟 2: 開啟 GitHub Pages

前往 GitHub 儲存庫頁面，點選 Settings → 左側 Pages → Build and deployment 的 Source 選擇 Deploy from a branch。

步驟 3: 設定主分支發布

Branch 選擇 main，目錄選擇 / (root)，點選 Save。約 1 分鐘後即可透過 https://kouou24.github.io/HW2_Linear_regression/ 線上預覽！
